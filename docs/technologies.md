# Tecnologias e Ferramentas

## Linguagens e Tecnologias Principais

- PHP: execução da aplicação web e do painel administrativo
- MySQLi: acesso ao banco de dados
- HTML5: estrutura das páginas
- CSS3: estilização visual
- JavaScript: interatividade e comportamento do front-end
- Apache .htaccess: reescrita de URLs e regras de roteamento

## Bibliotecas e Serviços Externos

- Font Awesome: ícones
- Google reCAPTCHA: validação de formulários
- Google Analytics / Google Tag Manager: rastreamento e análise

## Ambiente de Execução

- Servidor web com suporte PHP
- Banco MySQL/MariaDB
- Pastas de upload para arquivos de imagem

## Observações de Manutenção

As tecnologias atuais foram identificadas diretamente no código-fonte e nas dependências visíveis no projeto. A documentação foi organizada para refletir o estado atual do repositório sem introduzir novas tecnologias ou abstrações.
