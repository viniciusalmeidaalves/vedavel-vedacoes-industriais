# Requisitos do Projeto

## Requisitos Funcionais

- Apresentar a empresa Vedavel e seus diferenciais
- Exibir catálogo público de produtos
- Permitir navegação por categorias e subcategorias
- Exibir páginas de detalhe de produtos
- Receber mensagens de contato via formulário
- Disponibilizar painel administrativo para gerir categorias, subcategorias e produtos

## Requisitos Não Funcionais

- Interface responsiva para navegação em dispositivos diferentes
- Segurança básica por meio de sessões e consultas preparadas
- Compatibilidade com servidores web que suportem PHP e MySQL
- Suporte a URLs amigáveis por meio de reescrita de URL
- Organização simples de arquivos e templates reutilizáveis

## Dependências Externas

- Google reCAPTCHA para validação do formulário de contato
- Google Analytics/Tag Manager para monitoramento do site
- Font Awesome para ícones visuais
- Servidor de e-mail configurado para o envio de mensagens
